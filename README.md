# 💊 MedControl

**MedControl** é um sistema de gerenciamento farmacêutico desenvolvido para farmácias de pequeno porte. O objetivo é oferecer uma solução leve, funcional e educativa, ideal para projetos colaborativos e estudos de desenvolvimento web e backend.

---

## 🚀 Objetivos do Projeto

- Criar um sistema simples e funcional para farmácias regulares
- Utilizar tecnologias acessíveis para facilitar o aprendizado
- Simular operações reais como controle de estoque, vendas e vencimentos
- Promover boas práticas de desenvolvimento em equipe

## 📂 Estrutura do Sistema

O sistema será dividido em até 4 abas principais:

1. **Produtos** – Cadastro, edição, controle de estoque e vencimento
2. **Vendas** – Registro de vendas, emissão de cupom simulado
3. **Clientes** – Cadastro e histórico de compras
4. **Relatórios / Qualidade** – Relatórios de vencimento, estoque e conformidade

---

## 📋 Funcionalidades

- Cadastro de produtos com lote e validade
- Controle de estoque com regra PVPS (Primeiro que Vence, Primeiro que Sai)
- Alerta de vencimentos com etiquetas coloridas
- Registro de vendas e receitas médicas
- Relatórios mensais simulados para órgãos reguladores
- Cadastro de clientes e fornecedores
- Controle de acesso por tipo de usuário

---

## 🧪 Controle de Qualidade

O sistema inclui uma funcionalidade de controle de vencimentos com:

- Relatórios mensais automáticos
- Etiquetagem por cor (verde, laranja, vermelha)
- Simulação de envio para órgãos reguladores (ex: VISA Digital)
- Registro de descarte conforme normas da ANVISA
